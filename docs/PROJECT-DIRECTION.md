# Project direction — response to research review

Captured from the editorial review of *Designing Devin’s 127-Story Bedtime Bible*.

## Keep (core)

- **Tell less per story, but tell what you choose properly.**
- Episode ≠ Bible person (Moses / Dawid / Simson split into causal episodes).
- Constitutional accuracy rule + “do not remove the event; remove graphic detail.”
- Anti-invention (B / C / Q drafting tags).
- Dawid & Goliat sample as quality benchmark (lion/bear → five stones → sword/beheading in text; theology from David’s words).
- Visual direction: warm painterly realism; no VeggieTales / Marvel / photoreal Passion; no glowing Samson / magic auras / default halos / sky-grandfather God.
- Rhythm: wonder → … → peaceful landing. Intriguing ≠ overstimulating.
- Closing four anchors; prefer asking **Onthou jy?** tomorrow night.
