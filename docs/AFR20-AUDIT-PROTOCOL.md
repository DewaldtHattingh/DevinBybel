## Audit each story

1. Open **entire** primary passage chapter(s) on BibleSA AFR20 (not only the memory verse).  
2. Check: people, places, sequence, numbers/objects, divine attribution, dialogue facts.  
3. Fix manuscript: factual errors, wrong order, missing must-includes, memory-verse wording.  
4. Mark `afr20_quote_check: verified` only when the **Vers om te onthou** matches AFR20 word-for-word (or is clearly marked as paraphrase without quote marks).  
5. Log issues fixed in `docs/AFR20-AUDIT-LOG.md`.
