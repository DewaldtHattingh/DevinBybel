## Story shape (every file)

1. Opens: **Een dag, lank, lank gelede…**
2. Six designed pages with `![Beeld: …](../../assets/images/…)` + **Beeldnota**
3. Closes: **Wie was** / **Wat leer ons** / **Vers om te onthou** 〔AFR20-kontrole〕 / **Onthou jy?** (3 questions)
